## 一、快速开始

### 1.1 系统访问

打开浏览器，输入系统地址：

```
https://jieli-edu.example.com
```

> **支持的浏览器**: Chrome 90+ / Firefox 88+ / Edge 90+ / Safari 14+

### 1.2 账号体系说明

| 角色 | 账号类型 | 权限说明 |
|-----|---------|---------|
| 学生 | 练习账号 / 考试账号 | 参加考试、查看成绩 |
| 教师 | 教师账号 | 题库管理、组卷、考试监控、成绩批阅 |
| 管理员 | 管理账号 | 账号管理、系统配置、数据统计 |

## 二、学生使用指南

### 2.1 首次使用（账号激活）

**如果你收到了激活码，需要先激活账号：**

1. 访问系统首页，点击 **"使用激活码激活账号"**
2. 输入你的 **身份证号**（或用户名）
3. 输入 **激活码**（如：ABC123DEF456）
4. 设置登录密码（可选，不设置则使用默认密码）
5. 点击 **"激活账号"**

![激活流程](images/student-activate.png)

> **注意**: 
> - 激活码区分学段（小学/初中）和角色（学生/老师），请使用对应的激活码
> - 激活码只能使用一次，请妥善保管

### 2.2 登录系统

1. 输入 **身份证号** 或 **用户名**
2. 输入 **密码**
3. 点击 **"登录"**

![登录页面](images/student-login.png)

### 2.3 参加考试

#### 进入考试

1. 登录后进入 **"我的考试"** 页面
2. 查看可参加的考试列表
3. 找到状态为 **"进行中"** 的考试
4. 点击 **"进入考试"** 按钮

![我的考试](images/student-exams.png)

#### 答题操作

**页面布局说明：**

```
┌─────────────────────────────────────────────────────┐
│ 考试名称                    [剩余时间: 01:23:45]     │  ← 顶部标题栏
├──────────┬──────────────────────────────────────────┤
│          │                                          │
│  答题卡   │           题目内容                       │
│          │                                          │
│  ① ② ③   │    1. 这是什么题型？                     │
│  ④ ⑤ ⑥   │                                          │
│          │    ○ 选项A                               │
│  [提交]   │    ○ 选项B                               │
│          │    ○ 选项C                               │
│          │    ○ 选项D                               │
│          │                                          │
│          │    [上一题]              [下一题]        │
│          │                                          │
└──────────┴──────────────────────────────────────────┘
```

**答题步骤：**

1. **阅读题目** - 在右侧区域查看题目内容
2. **选择答案** - 点击选项进行选择
   - 单选题：圆形单选框
   - 多选题：方形多选框，可选择多个
   - 判断题：选择"正确"或"错误"
   - 主观题：在文本框中输入答案，可上传附件
3. **答题卡导航** - 点击左侧答题卡的题号快速跳转
4. **保存进度** - 系统会自动保存答题进度（每30秒）
5. **切换题目** - 使用 **"上一题"** / **"下一题"** 按钮

#### 提交试卷

**完成所有题目后：**

1. 检查答题卡，确保所有题目已作答（绿色标记）
2. 点击右上角的 **"提交试卷"** 按钮
3. 在弹出的确认框中点击 **"确认提交"**
4. 提交成功后，系统显示成绩（客观题部分）

> **重要提示**:
> - 考试时间到会自动提交，请合理安排时间
> - 提交后无法修改答案，请谨慎操作
> - 主观题需要等待老师批阅后才有成绩

#### 考试注意事项

| 情况 | 处理方式 |
|-----|---------|
| 意外关闭页面 | 重新登录，答案会自动恢复 |
| 网络中断 | 答题已保存在本地，恢复网络后自动同步 |
| 电脑死机 | 重启后重新登录，从断点继续 |
| 时间不够 | 系统会自动提交，确保已答题得分 |

### 2.4 查看成绩

1. 考试结束后，进入 **"我的成绩"** 页面
2. 查看所有已参加的考试成绩
3. 点击 **"查看详情"** 可查看答题详情

![成绩页面](images/student-scores.png)

**成绩组成：**

- **客观题分数**：系统自动评分（单选、多选、判断）
- **主观题分数**：老师批阅后给出
- **总分**：客观题 + 主观题
- **排名**：在所有考生中的排名

## 三、教师使用指南

### 3.1 登录与首页

使用教师账号登录后，进入 **"教师工作台"**：

![教师工作台](images/teacher-dashboard.png)

**工作台显示：**

- 我的题库数量
- 已创建套卷数量
- 进行中的考试数量
- 待批阅试卷数量
- 最近考试列表

### 3.2 题库管理

#### 创建题库

1. 点击左侧菜单 **"题库管理"**
2. 点击 **"+ 新建题库"** 按钮
3. 填写题库信息：
   - **题库名称**：如"小学编程基础"
   - **学段**：小学组 / 初中组
   - **描述**：题库简介
4. 点击 **"确定"** 创建

![创建题库](images/teacher-create-bank.png)

#### 添加题目

1. 进入题库详情页
2. 点击 **"添加题目"** 按钮
3. 选择题型：

**单选题：**
- 输入题目内容
- 添加4个选项（A/B/C/D）
- 选择正确答案
- 设置分值（默认2分）
- 选择难度（简单/中等/困难）
- 添加解析（可选）

**多选题：**
- 输入题目内容
- 添加选项
- 选择多个正确答案
- 设置计分方式：
  - 固定分值：少选得固定分
  - 按选项计分：选对几个得几分
  - 按比例计分：按正确比例得分

**判断题：**
- 输入题目内容
- 选择正确/错误
- 设置分值

**主观题：**
- 输入题目内容
- 输入参考答案
- 设置分值
- 添加评分要点（供批阅参考）

#### 批量导入题目

1. 点击 **"批量导入"** 按钮
2. 下载 Excel 模板
3. 按模板格式填写题目
4. 上传文件
5. 系统自动解析并导入

**Excel模板格式：**

| 题目内容 | 题型 | 选项A | 选项B | 选项C | 选项D | 正确答案 | 分值 | 难度 | 解析 |
|---------|------|-------|-------|-------|-------|----------|------|------|------|
| 1+1=? | 单选 | 1 | 2 | 3 | 4 | B | 2 | 简单 | 基础加法 |

### 3.3 套卷管理

#### 创建套卷

1. 点击 **"套卷管理"** 菜单
2. 点击 **"新建套卷"**
3. 填写套卷信息：
   - **套卷名称**：如"2026年春季初赛"
   - **适用学段**：小学组/初中组
   - **考试时长**：120分钟
   - **总分**：自动计算

#### 组卷操作（拖拽选题）

**页面布局：**

```
┌──────────────────────────────────────────────────────┐
│ 套卷名称: 2026年春季初赛               [总分: 100]   │
├──────────────┬──────────────┬────────────────────────┤
│              │              │                        │
│   题库筛选    │   题目列表    │      已选题目          │
│              │              │                        │
│  [题库下拉]   │  1. 题目一   │  1. 题目一     [删除]  │
│              │      [添加]   │  2. 题目二     [删除]  │
│  [题型筛选]   │  2. 题目二   │  3. 题目三     [删除]  │
│              │      [添加]   │                        │
│  [难度筛选]   │  3. 题目三   │  [调整分值]            │
│              │      [添加]   │                        │
│              │              │  [保存草稿] [发布套卷]  │
└──────────────┴──────────────┴────────────────────────┘
```

**操作步骤：**

1. **选择题库** - 在左侧选择要选题的题库
2. **筛选题目** - 可按题型、难度筛选
3. **添加题目** - 点击题目右侧的 **"+"** 按钮或拖拽到右侧
4. **调整顺序** - 在右侧拖拽题目调整顺序
5. **设置分值** - 点击每题的分值进行修改
6. **删除题目** - 点击题目右侧的 **"删除"** 按钮
7. **保存/发布** - 点击 **"保存草稿"** 或 **"发布套卷"**

> **注意**: 套卷发布后不能再修改，如需修改请创建新版本

### 3.4 考试管理

#### 创建考试

1. 点击 **"考试管理"** 菜单
2. 点击 **"创建考试"**
3. 填写考试信息：

**基本信息：**
- 考试名称
- 选择套卷（已发布的）
- 考试开始时间
- 考试结束时间
- 考试时长（分钟）

**高级设置：**
- 考生名单（可导入Excel）
- 防作弊设置（切屏限制、IP限制等）
- 及格分数线

#### 发布考试

1. 在考试列表中找到草稿状态的考试
2. 点击 **"发布"** 按钮
3. 确认发布后，考试进入 **"待开放"** 状态
4. 到达开始时间后自动开放

#### 考试监控

**进入监控页面：**

1. 点击考试列表中的 **"监控"** 按钮
2. 或点击 **"考试看板"** 菜单

**监控内容：**

- **实时统计**：应到/实到/答题中/已提交人数
- **考生列表**：每位考生的实时状态
- **异常预警**：未登录、长时间无操作等

**监控操作：**

| 操作 | 适用场景 | 操作步骤 |
|-----|---------|---------|
| 强制交卷 | 考生违规或时间到 | 点击考生行 → 点击"强制交卷" → 确认 |
| 标记异常 | 考生有作弊嫌疑 | 点击考生行 → 点击"标记异常" → 填写原因 |
| 紧急延时 | 全体需要延长时间 | 点击"紧急延时" → 输入延时时长 → 确认 |

![考试监控](images/teacher-monitor.png)

### 3.5 成绩批阅

#### 客观题成绩

- 自动评分，无需人工干预
- 可在成绩页面查看统计

#### 主观题批阅

1. 点击 **"成绩管理"** → **"主观题批阅"**
2. 选择要批阅的考试
3. 进入批阅页面：

**批阅界面：**

```
┌─────────────────────────────────────────────────────┐
│ 题目: 简述Python中列表和元组的区别                    │
├─────────────────────────────────────────────────────┤
│                                                     │
│  参考答案:                                          │
│  1. 列表可变，元组不可变                            │
│  2. 列表用[]，元组用()                              │
│  3. 元组性能略优                                    │
│                                                     │
├─────────────────────────────────────────────────────┤
│  学生答案:                                          │
│  列表可以修改，元组不能修改。列表用方括号，          │
│  元组用圆括号。                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│  评分: [________] / 10 分                           │
│  评语: [_________________________________]          │
│                                                     │
│          [上一题] [跳过] [保存并下一题]              │
└─────────────────────────────────────────────────────┘
```

**批阅步骤：**

1. 阅读题目和学生答案
2. 对照参考答案进行评分
3. 输入分数（0-满分）
4. 可添加评语（可选）
5. 点击 **"保存并下一题"** 继续批阅

> **提示**: 系统会锁定正在批阅的题目，防止其他老师同时批阅

#### 成绩导出

1. 进入成绩管理页面
2. 选择考试
3. 点击 **"导出成绩"** 按钮
4. 选择格式（Excel/CSV）
5. 如果数据量大，系统会创建异步导出任务
6. 导出完成后下载文件

### 3.6 资源中心

#### 上传资源

1. 点击 **"资源中心"** 菜单
2. 点击 **"上传资源"**
3. 选择文件（支持PDF、PPT、视频等）
4. 选择分类（如"教学视频/基础篇"）
5. 填写资源名称和描述
6. 点击 **"上传"**

> **注意**: 大文件（>50MB）会自动使用分片上传

#### 资源预览

- 点击资源名称可在线预览
- PDF和PPT支持在线预览
- 视频支持在线播放
- **注意**: 资源禁止下载，仅供在线学习

## 四、管理员使用指南

### 4.1 管理控制台

登录后进入 **"管理控制台"**，显示系统概览：

![管理控制台](images/admin-dashboard.png)

- 考试场次统计
- 系统资源使用情况

### 4.2 账号管理

#### 批量生成账号

**练习账号（赛前练习用）：**

1. 点击 **"批量生成账号"**

**线上分发（推荐日常使用）：**

- 通过邮件/短信发送
- 系统记录分发状态

#### 激活码查询

- 搜索特定激活码
- 查看已使用/未使用的激活码
- 作废未使用的激活码（如有需要）

### 4.4 系统监控

## 五、常见问题

### Q1: 忘记密码怎么办？

**学生/老师：**
1. 联系管理员重置密码
2. 管理员可在账号管理中重置

**管理员：**
1. 通过数据库直接修改
2. 或使用命令行工具重置

### Q2: 考试中途断网怎么办？

- 答案已自动保存到本地
- 恢复网络后自动同步
- 刷新页面后可继续答题
- 考试时间会继续计算

### Q3: 为什么激活码无法使用？

可能原因：
- 激活码已过期
- 激活码已被使用
- 学段不匹配（小学码不能激活初中账号）
- 激活码输入错误（区分大小写）

### Q4: 如何查看所有题目的答案？

- 考试结束后可查看自己的答案
- 老师可在题库中查看标准答案
- 学生只能查看自己的答题情况

### Q5: 导出成绩时提示"数据量太大"？

- 系统会自动转为异步导出
- 等待几分钟后刷新页面
- 在"导出任务"中下载结果

### Q6: 视频上传失败怎么办？

- 检查文件大小（最大2GB）
- 检查网络连接
- 尝试使用分片上传
- 联系管理员检查服务器存储空间

### Q7: 可以同时登录多个设备吗？

- **不可以**。新登录会踢出旧会话
- 这是为了防止账号共享
- 建议固定使用一台设备

## 六、注意事项

### 6.1 安全须知

1. **保护账号密码**：不要告诉他人
2. **及时退出**：使用完后点击退出登录
3. **防范钓鱼**：只访问官方地址
4. **举报异常**：发现异常及时报告

### 6.2 考试纪律

1. **独立完成**：禁止抄袭或协助他人
2. **禁止作弊**：不要使用外挂或搜索答案
3. **遵守时间**：不要超时答题
4. **诚信考试**：违规将被取消成绩

### 6.3 技术支持

遇到问题可联系：

- **技术支持热线**: 400-XXX-XXXX（工作日 9:00-18:00）
- **在线客服**: 系统内右下角客服窗口
- **邮箱支持**: support@jieli-edu.com

### 6.4 反馈建议

如有功能建议或发现问题，请通过以下方式反馈：

- 系统内 **"意见反馈"** 功能
- 发送邮件至 feedback@jieli-edu.com
- 联系您的老师或管理员
