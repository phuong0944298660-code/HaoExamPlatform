Global Styles 全局样式
跨页面的 UI 修正统一放在 frontend/src/styles/layout-override.css。颜色与间距优先使用 frontend/src/styles/design-system.css 中的 CSS 变量。
变量值用途
--primary-500#1890ff品牌主色
--success-500#52c41a成功
--error-500#f5222d错误
--text-primary#262626主要文本
--text-secondary#595959次要文本
--space-416px常用间距
--space-624px页面/卡片间距
