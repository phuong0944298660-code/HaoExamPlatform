## ❌ 失败的测试分析 (27个)

### 1. 登录流程相关 (7个)
**原因**: 后端API未运行，无法进行真实的登录验证

```
- 登录成功流程 - 管理员 (timeout)
- 登录按钮样式 (选择器问题)
- 页面整体布局和样式验证 (height计算)
```

**修复建议**: 
- 启动后端服务: `docker-compose up -d`
- 或使用mock数据模式

### 2. 账号管理模块 (7个)
**原因**: 需要先登录管理员账号才能访问

```
- 页面整体布局验证
- 标签页导航验证
- 筛选区域像素级验证
- 表格列验证
- 批量生成按钮验证
- 弹窗验证
```

**修复建议**: 使用setup文件预先登录，或mock用户状态

### 3. 考试流程 (3个)
**原因**: 需要登录状态和有数据的考试

```
- 学生首页布局验证
- 考试卡片样式验证
- 考试状态标签验证
```

### 4. 视觉回归测试 (10个)
**原因**: 缺少截图基线文件

```
- 登录页面视觉回归

- ...
```

**修复建议**:

## 🔧 如何运行测试

### 1. 仅运行认证模块测试
```bash
cd e2e
npx playwright test playwright-tests/auth.spec.ts --project=chromium
```

### 2. 运行所有测试
```bash
cd e2e
npx playwright test
```

### 3. 带UI模式运行（调试）
```bash
cd e2e
npx playwright test --ui
```

### 4. 生成截图基线
```bash
cd e2e
npx playwright test --update-snapshots
```

### 5. 查看HTML报告
```bash
cd e2e
npx playwright show-report
```
