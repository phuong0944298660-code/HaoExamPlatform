## 📋 测试场景推荐

### 场景1：完整的考试流程
```
1. 教师创建题库 → 录入试题
2. 教师创建考试 → 设置场次时间
3. 学生登录 → 进入考试
4. 学生答题 → 提交试卷
5. 教师查看成绩 → 导出成绩表
```

### 场景2：账号激活流程
```
1. 管理员生成激活码
2. 新学生使用激活码注册
3. 已有学生叠加激活新权限
4. 验证权限是否正确叠加
```

### 场景3：班级管理
```
1. 教师创建班级
2. 添加学生到班级
3. 查看班级成绩统计
4. 导出班级成绩
```
