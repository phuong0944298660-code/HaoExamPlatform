```bash
# 运行检查脚本

# 检查项目包括：
# - 服务状态
# - 端口监听
# - 数据库连接
# - Redis连接
# - 磁盘空间
# - 内存使用
```

### 手动验证命令

```bash
# 1. 检查服务状态
docker-compose ps

# 2. 检查API健康
curl -f https://your-domain/api/v1/health || echo "API异常"

# 3. 检查数据库
docker-compose exec db mysql -u root -p -e "SELECT 1"

# 4. 检查Redis
docker-compose exec redis redis-cli ping

# 5. 检查磁盘
df -h | grep -E "(Filesystem|/dev/)"

# 6. 检查内存
free -h
```
