## 三、代码审查关键问题（v2.0 新增）

### 3.1 致命问题：前端Mock假数据

| 页面 | Mock方式 | 已就绪但未调用的API | 影响 |
|------|---------|-------------------|------|
| teacher/Scores.vue | `mockExamList` + `generateMockScores()` 随机生成456条数据 | `getScores()`, `exportScores()` | 教师无法查看/导出真实成绩 |
| teacher/Resources.vue | `mockResources` 硬编码6条 + `setInterval` 模拟上传 | `getResources()`, `uploadResource()`, `deleteResource()` | 资源中心完全不可用 |
| teacher/ExamDashboard.vue | `weightedRandom()` 生成456条假学生状态 | `getExamDashboard()`, `getExamStudents()` | 考试监控无法使用 |
| student/ExamResult.vue | `submitted` 硬编码为 `true`，无API调用 | `GET /scores/{exam_id}/students/{account_id}` | 学生看不到成绩 |

### 3.2 重要问题：后端功能缺失

| 问题 | 详情 | 影响 |
|------|------|------|
| WebSocket路由未注册 | `ExamWebSocketManager` 类完整但无FastAPI端点 | 实时同步/强制提交推送不工作 |
| 考试无更新/删除API | 仅有 POST（创建）、GET（列表/详情） | 创建后无法修改，只能重建 |
| 自动提交未触发 | `check_exam_status_transitions` 转FINISHED但不调用 `auto_submit_exam` | 超时学生答案可能丢失 |
| 文件服务端点缺失 | 无 StaticFiles mount 或下载API | 上传文件无法通过HTTP访问 |

### 3.3 重要问题：数据模型偏离

| 问题 | 规范要求 | 实际实现 |
|------|---------|---------|
| 分数列类型 | `DECIMAL(5,2)` | `Float`（存在精度问题） |
| 唯一约束缺失 | `(exam_id, account_id)` 应唯一 | 无约束，可重复分配 |
| `submission_ip` 未赋值 | 提交时记录IP | 从未赋值 |
| 软删除不一致 | `SoftDeleteMixin` | Resource 使用 `is_active` |

### 3.4 重要问题：API安全性

大部分路由（scores, exams, resources, papers, questions）缺少角色权限检查，任何登录用户可执行管理员操作。仅 `exam_engine.py` 有基本的学生分配关系检查。
