## 🚀 使用方式

### 运行全部测试
```bash
cd e2e

# 运行所有测试
npx playwright test

# 运行Agent测试
npx playwright test agents/ --reporter=line

# 运行专项测试
npx playwright test specs/ --reporter=line

# 运行回归测试
npx playwright test playwright-tests/ --reporter=line

# 准备测试数据
npx playwright test setup-test-data.spec.ts
```

### 运行单个测试文件
```bash
npx playwright test agents/account-activation-agent.ts
npx playwright test agents/exam-flow-agent.ts
npx playwright test specs/activation-codes.spec.ts
```

### 生成报告
```bash
npx playwright test --reporter=html
npx playwright show-report
```
